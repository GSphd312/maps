Chapter 25 The Core Concept

Understanding secondary analysis

This lab is about secondary data analysis, which means using data collected by someone else. The CDC gathered this NHANES data. Our job is to ask a new question using their variables, keeping in mind the limits of a cross-sectional design.

What secondary data give you

  • Individual-level exam data; each file has a codebook.
  • You are limited to variables others measured.
  • Cross-sectional design means we find associations, never causation.

The variables this lab uses

NameMeaning
SEQNParticipant ID (merge key)
RIDAGEYRAge in years
RIAGENDRSex (numeric → factor)
BMXBMIBody mass index (kg/m²)
BPXSY11st systolic BP (mmHg)

Question & hypothesis

RQ. Is obesity associated with elevated systolic BP among adult NHANES 2017–2018 participants?

H1. Adults with obesity have higher SBP and higher odds of elevated BP than adults without.

Exposure = BMI/obesity, outcome = SBP / elevated SBP, covariates = age, sex.

A quick note on survey weights. NHANES uses a complex survey design. We are skipping the weights in this lab for simplicity, so frame your final write-up as an analysis of this specific sample, not the entire US population.

Chapter 28 Import, clean, merge and recode

Data management

Never overwrite your raw variables and always create new, derived variables for your actual analysis so your downstream code doesn't break.

Pull the raw files

demo_raw <- nhanes("DEMO_J")  # demographics
bmx_raw  <- nhanes("BMX_J")   # body measures
bpx_raw  <- nhanes("BPX_J")   # blood pressure

nrow(demo_raw); names(demo_raw)

Tidy names, then merge on SEQN

demo <- clean_names(demo_raw)  # SEQN to seqn
bmx  <- clean_names(bmx_raw)
bpx  <- clean_names(bpx_raw)

adults_raw <- demo %>%
  left_join(bmx, by = "seqn") %>%
  left_join(bpx, by = "seqn")

anti_join(demo, bpx, by="seqn") %>% nrow()

Which rows a join keeps

JoinKeeps
left_joinall left + matches (used)
right_joinall right + matches
inner_joinonly matched rows
full_joinall rows, both sides
anti_joinleft rows with no match

No match means new columns become NA.

Filter to adults, then derive every analysis variable

adults <- adults_raw %>%
  filter(ridageyr >= 18) %>%
  transmute(
    seqn, age = ridageyr,
    sex = factor(riagendr,
          levels=c("Male","Female")),
    bmi = bmxbmi, sbp = bpxsy1,
    obese = if_else(bmi>=30, 1, 0,
            missing = NA_real_),
    obese_f = factor(obese, c(0,1),
      labels=c("Not obese","Obese")),
    bmi_cat = case_when(
      bmi<18.5 ~ "Underweight",
      bmi<25   ~ "Normal weight",
      bmi<30   ~ "Overweight",
      bmi>=30  ~ "Obese",
      TRUE ~ NA_character_),
    htn = if_else(sbp>=130, 1, 0,
          missing = NA_real_),
    htn_f = factor(htn, c(0,1),
      labels=c("No elevated SBP",
               "Elevated SBP"))) %>%
  drop_na(age, sex, bmi, sbp,
          obese, bmi_cat, htn)

Inspect & save

nrow(adults); glimpse(adults)
colSums(is.na(adults))   # missingness
table(adults$obese_f)    # both levels?
table(adults$bmi_cat)
write_csv(adults, "adults_nhanes_clean.csv")

Chapter 30, bivariate tests and nonparametric tests

Comparative statistics

Pick the test from the variable types, check its assumptions, and run a nonparametric test if violating the normality. With n ≈ 4,800, report both p-value and effect sizes.

Choosing the test

SituationParametric Test to Nonparametric Test
2 meanst test → Wilcoxon
2 categoricalschi-square → Fisher
3+ meansANOVA → Kruskal-Wallis
2 continuousPearson → Spearman
stat vs value1-sample t / binom

Two independent means

adults %>% group_by(obese_f) %>%
  summarise(n=n(), mean=mean(sbp), sd=sd(sbp))

leveneTest(sbp ~ obese_f, data=adults)
t.test(sbp ~ obese_f, data=adults) # Welch
wilcox.test(sbp ~ obese_f, data=adults)
LeveneUse
p ≤ .05 (unequal)Welch (default)
p > .05 (equal)var.equal=TRUE

Two categoricals

tab <- table(adults$obese_f, adults$htn_f)
prop.table(tab, margin=1)  # row %

chi <- chisq.test(tab)
chi$expected; chi
fisher.test(tab)           # if expected < 5

sqrt(chi$statistic /        # Cramér's V
  (sum(tab)*(min(dim(tab))-1)))

V / φ: .10 small, .30 medium, .50 large.

Three or more means

# equal variances
fit_aov <- aov(sbp ~ bmi_cat, data=adults)
summary(fit_aov); TukeyHSD(fit_aov)

# unequal variances (Welch)
oneway.test(sbp ~ bmi_cat, data=adults)
rstatix::games_howell_test(adults, sbp ~ bmi_cat)

# nonparametric
kruskal.test(sbp ~ bmi_cat, data=adults)
FSA::dunnTest(sbp ~ bmi_cat, data=adults,
  method="bonferroni")

ANOVA decision path

CheckOverall to post-hoc
Variance OKANOVA → Tukey HSD
Variance failsWelch → Games-Howell
Non-normalKruskal → Dunn
rstatix::eta_squared(fit_aov)        # η²
rstatix::kruskal_effsize(adults, sbp ~ bmi_cat)

Two continuous variables

plot(adults$bmi, adults$sbp)
abline(lm(sbp ~ bmi, data=adults), col="red")

cor.test(adults$bmi, adults$sbp, method="pearson")
cor.test(adults$bmi, adults$sbp, method="spearman")

r² previews the simple-regression R². Association, not causation.

A statistic vs a set value

t.test(adults$sbp, mu=120)   # mean vs 120
binom.test(sum(adults$obese==1),
  n=nrow(adults), p=0.40)     # prev. vs .40

Choose the reference value before seeing the data.

Significance is not the same as importance. With n = 4,833, a Cramér's V of 0.065 still clears p < .001. Always report effect size, direction, and CI beside the p-value. Paired and repeated-measures tests do not apply because each adult is measured once.

Chapter 31, adjusted models and diagnostics

Regression analysis

Fit adjusted models, check their assumptions, and interpret the estimate in plain language. We want a coefficient for continuous outcomes and an odds ratio for binary ones.

Model by outcome type

OutcomeModel to estimate
Continuous (SBP)linear → β coefficient
Binary (htn)logistic → odds ratio

Multiple linear regression

fit_lm <- lm(sbp ~ bmi + age + sex, data=adults)
summary(fit_lm); confint(fit_lm)

broom::tidy(fit_lm, conf.int=TRUE)
broom::glance(fit_lm)   # adj R²

β = mean change in SBP per 1-unit predictor, holding others constant.

Linear diagnostics

car::vif(fit_lm)         # <5 ok
plot(fit_lm, which=1)    # resid vs fit
plot(fit_lm, which=2)    # Q-Q
lmtest::bptest(fit_lm)   # Breusch-Pagan
max(cooks.distance(fit_lm))
BP testMeans
p > .05homoscedastic — std SE fine
p < .05use robust SE

Robust (HC3) standard errors

library(sandwich); library(lmtest)
coeftest(fit_lm,
  vcov = vcovHC(fit_lm, type="HC3"))

Run when Breusch-Pagan is significant. Fixes SEs, not coefficients.

Multiple logistic regression

fit_logit <- glm(htn ~ obese_f+age+sex,
  data=adults, family=binomial)
summary(fit_logit)

exp(cbind(OR=coef(fit_logit),       # ORs + CI
  confint.default(fit_logit)))
broom::tidy(fit_logit, conf.int=TRUE,
  exponentiate=TRUE)

OR for obese_fObese = obese vs reference. CI excluding 1 ⇔ p < .001.

Logistic checks

car::vif(fit_logit)
sum(adults$htn==1) /             # events per var
  (length(coef(fit_logit))-1)
ResourceSelection::hoslem.test(
  adults$htn, fitted(fit_logit), g=10)
max(cooks.distance(fit_logit))

Hosmer-Lemeshow is over-sensitive at large n. Check with EPV and Cook's D.

Categorical predictors (dummies)

fit_d <- lm(sbp ~ bmi_cat, data=adults)
contrasts(adults$bmi_cat)  # see 0/1

adults$bmi_cat <- relevel(    # new baseline
  adults$bmi_cat, ref="Normal weight")
fit_d <- lm(sbp ~ bmi_cat, data=adults)

n categories → n−1 dummies; omitted level = reference.

Confounding: crude vs adjusted

fit_crude <- glm(htn ~ obese_f,
  data=adults, family=binomial)
crude <- exp(coef(fit_crude))["obese_fObese"]
adj   <- exp(coef(fit_logit))["obese_fObese"]
(adj-crude)/crude*100   # % change

> ~10% shift ⇒ possible confounding by age or sex.

Effect modification

# stratum-specific ORs by sex
by_sex <- split(adults, adults$sex)
lapply(by_sex, function(d)
  exp(coef(glm(htn ~ obese_f+age, data=d,
    family=binomial)))["obese_fObese"])

fit_int <- glm(htn ~ obese_f*sex + age,
  data=adults, family=binomial)
  • Strata are close to each other but distinct from crude data → confounding.
  • Strata vary significantly from one another → effect modification.
Association is not causation. Use phrases like "obesity was associated with elevated SBP" instead of saying it caused it. Cross-sectional data cannot establish a clear timeline, which is the baseline requirement for determining cause.

Reproducibility

Treat the analysis as an open scholarship workflow. Make sure to preserve raw files, do every single change inside R, and document your steps well enough that someone else can rerun it without confusion.

Project structure

secondary_analysis_lab/
  data_raw/      # never edit
  data_clean/    # R output
  code/  output_tables/
  output_figures/  dictionary/
  manuscript/  README.txt

dirs <- c("data_raw","data_clean","code",
  "output_tables","output_figures",
  "dictionary","manuscript")
purrr::walk(dirs, dir.create,
  showWarnings=FALSE, recursive=TRUE)

Preserve the originals

write_csv(demo_raw,"data_raw/DEMO_J_raw.csv")
write_csv(adults,
  "data_clean/nhanes_2017_2018_adults_clean.csv")

Never edit a CSV in Excel and resave it as the analysis file — recode in R.

Document the work

A data dictionary holds one row per analytic variable: name, label, source file, original variable, coding, and role. The README states the question, data sources, and access dates, run order, R package versions, and expected outputs.
